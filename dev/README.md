# Cap — sources de développement

- La racine du dépôt est l'appli publiée sur GitHub Pages (version autonome, données sur l'appareil).
- `dev/tests/tests.js` : tests du moteur de calcul (`node dev/tests/tests.js` depuis un dossier contenant engine.js).
- `dev/tests/ui3.js`, `sk.js`, `dir.js` : tests d'interface Playwright (iPhone simulé).
- `dev/docs/` : matrice de parité, règles de calcul, design system, plan, rapport de tests.
- La même appli est aussi publiée dans Claude (avec scan photo et coach) ; seule la ligne du mode sans compte diffère dans app.js.
